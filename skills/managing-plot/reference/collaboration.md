# Collaboration

Read a document's full Markdown before replacing it. Updates replace supplied
content; preserve existing sections unless the user requests a rewrite. Create
documents in the intended area so permissions and collaborators remain correct.

Use comments for discussion on an existing task or project. A Markdown comment
is stored by Plot API, which owns mention parsing and notifications. Resolve
people with user tools before mentioning them. Do not invent a mention syntax or
claim a notification was delivered based only on a submitted comment.

Use activity to understand recent changes, and inbox tools for the connected
user's notifications. Mark read or archive only the notifications the user asked
to change. Comments and activity lists are paginated; a first page is not a
complete history. The public posts list returns top-level comments, not replies.
